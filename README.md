# Diabetes Prediction Using Machine Learning

## Project Overview

This project uses Machine Learning to predict whether a person is likely to have diabetes based on several medical and health-related features. The model is trained using a Support Vector Machine (SVM) classifier with a linear kernel.

The project includes data analysis, data preprocessing, feature standardization, model training, model evaluation, and a predictive system for making predictions on new input data.

## Dataset

The dataset used in this project contains medical information related to diabetes. The target variable is `Outcome`.

* `0` → Non-diabetic
* `1` → Diabetic

## Features Used

The model uses the following features:

* Pregnancies
* Glucose
* BloodPressure
* SkinThickness
* Insulin
* BMI
* DiabetesPedigreeFunction
* Age

## Technologies Used

* Python
* NumPy
* Pandas
* Scikit-learn
* Jupyter Notebook

## Machine Learning Model

The model used in this project is a Support Vector Machine (SVM) classifier with a linear kernel.

```python
classifier = svm.SVC(kernel='linear')
```

## Project Workflow

1. Import the required libraries.
2. Load the diabetes dataset using Pandas.
3. Perform basic data analysis and statistical exploration.
4. Separate the input features and target variable.
5. Split the dataset into training and testing data.
6. Standardize the features using `StandardScaler`.
7. Train a Support Vector Machine classifier.
8. Evaluate the model using accuracy score.
9. Use the trained model to make predictions on new data.

## Model Evaluation

The model is evaluated using accuracy score on both the training and testing datasets.

The training accuracy helps measure how well the model performs on the data used for training, while the testing accuracy helps evaluate how well the model generalizes to unseen data.

## Predictive System

The project includes a predictive system that accepts medical feature values as input, standardizes the input using the trained scaler, and predicts whether the person is likely to have diabetes.

Example:

```python
input_data = (1, 189, 60, 23, 846, 30.1, 0.398, 59)
```

The model then predicts one of the following outcomes:

* `0` → The person is predicted not to have diabetes.
* `1` → The person is predicted to have diabetes.
